# Diabetes-Analysis
Analyze diabetes with a support vector machine for Practical-Homework-2-class 5322

**Project Overview**

This project involves building and evaluating a predictive model to identify diabetes status in adults. The analysis was conducted as part of a technical assignment to demonstrate proficiency in data processing and model evaluation using R.

**Key Feature**

- **Data processing:** implements scaling and partitioning of datasets for robust modeling testing. 
- **Predictive Analysis:** using R-based modeling to generate predictions on health outcomes. 
- **Performance Analysis:** evaluate using Accuracy, F1 score, and Area under the curve (AUC).

**Tools and Technologies**

- Language: R
- Key libraries: confusingMatrix and  ROC for performance evaluation
- Reporting: generated using Pandoc with Bootstrap for responsive table styling.

**Model Performance**

The current best-performing model achieved the following results:

- Accuracy: 0.6987
- F1 Score: 0.7087
- AUC: 0.7005

**How to run**
- Ensure R and loaded necessary packages
- Load dataset and pre-processed scaled data
- Run the prediction script to generate confustion matrix and ROC analysis
